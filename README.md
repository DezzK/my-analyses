# Мои анализы

Приложение для macOS, Windows и Linux, которое хранит результаты анализов семьи: забирает их из личных
кабинетов лабораторий, показывает таблицами и графиками и собирает отчёты для врача — на печать или в PDF.

- Импорт из личного кабинета [KDL](https://kdl.ru) через встроенный браузер: вы входите сами, пароли
  приложение не хранит. Бланки лаборатории сохраняются как есть. Результаты можно вводить и вручную.
- Справочник показателей: синонимы и коды лабораторий, единицы с пересчётом, нормы с учётом пола,
  возраста, беременности и фазы цикла.
- Таблицы и графики по каждому показателю, отчёты по шаблонам.
- Все данные остаются на компьютере, резервные копии — в выбранной вами папке. В сеть приложение ходит
  только к сайтам лабораторий и сюда, за обновлениями.

## Установка

Сборки — в [последнем релизе](https://github.com/DezzK/my-analyses/releases/latest).

- **macOS** — одной командой в Терминале (она же ставит новую версию поверх старой):

  ```bash
  curl -fsSL https://github.com/DezzK/my-analyses/releases/latest/download/install.sh | bash
  ```

- **Windows** — скачайте и запустите установщик `…-setup.exe`. Windows предупредит о неизвестном издателе:
  нажмите «Подробнее» → «Выполнить в любом случае».
- **Linux** — скачайте файл `.AppImage`, разрешите запуск (`chmod +x`) и запустите.

Дальше установленное приложение обновляется само: macOS-сборка принимает обновление, только если оно
подписано тем же ключом, что и она сама.

## Важно

«Мои анализы» — не медицинское изделие. Приложение не ставит диагнозов и не заменяет консультацию врача:
отметки об отклонениях лишь сравнивают результат с нормами лаборатории и справочника и могут ошибаться.
